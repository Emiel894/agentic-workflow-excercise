### From Awesome Copilot workflows

Ready-to-adapt agentic workflows for automating repository chores. Source: [Awesome Copilot workflows](https://awesome-copilot.github.com/workflows/).

- `daily-issues-report`: a daily summary of repository issues.
- `weekly-comment-sync`: keeps comments in sync on a weekly schedule.
- `ospo-stale-repos`, `ospo-org-health`, `ospo-contributors-report`, `ospo-release-compliance-checker`: open source program office (OSPO) reports for stale repos, org health, contributors, and release compliance.
- `relevance-check` and `relevance-summary`: check and summarize whether content is still relevant.
